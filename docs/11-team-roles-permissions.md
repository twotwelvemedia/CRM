# Team Roles & Permissions

Create these roles under Settings → Team → Roles **before** inviting staff, so nobody briefly has more access than they should.

| Module | Owner/Admin | Producer/PM | Editor | Videographer | Sales/Account Mgr |
|---|---|---|---|---|---|
| CRM (Contacts/Companies/Deals) | Full | Full | View | None | Full |
| Projects & Tasks | Full | Full | Edit (assigned only) | Edit (assigned only) | View |
| Proposals & Contracts | Full | Full | None | None | Full |
| Invoices & Payments | Full | View | None | None | View |
| Client Portal content management | Full | Edit | None | None | None |
| Workflows/Automations | Full | View | None | None | None |
| Settings/White Label | Full | None | None | None | None |
| Reports | Full | Full | None | None | Full (sales reports) |

## Notes

- Scope Editor and Videographer permissions to **assigned tasks/projects only** (not the full client list or financials) — this matters most once you bring on freelancers/contractors.
- Sales/Account Manager gets full CRM and Proposal/Contract access but only *view* on invoices — they can see what's owed without being able to alter billing.
- Revisit this table once your team grows past these five roles; it's deliberately minimal for a small studio.
