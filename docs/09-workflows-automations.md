# Automations

**Correction from earlier (Plutio-era) planning:** there's no single global "Automations builder" in SuiteDash the way Plutio had one. Automations are configured per-object instead — on a Task Template's individual task (row ⋮ → **Manage Automations** → **Configure Automations**), or on an Invoice Generator/Subscription (its own **Assign Automations** section, e.g. "Invoice is Paid" / "Invoice is Past Due"). Each one still pairs a **trigger** (this task's completion requirement is met, this invoice is paid, etc.) with one or more **actions**, picked from a shared action library (Send Email to Target, Create Task, On-Demand/Recurring/Accumulating Invoice Generator, Apply Task Template, and more). Email bodies referenced are in `templates/emails/`.

**Automation #1 detail:** originally designed around "Won + Deposit Paid," but contracts and deposits aren't consistent across every job (some have neither) — no single upstream event reliably signals "this job is starting" the way a card landing on a specific column would. Project creation itself would be the one universal, always-true moment, but **SuiteDash has no "Project created" trigger type to attach an automation to** (task automations fire off a task's own completion requirement, not a Project-level lifecycle event, confirmed by inspecting the full action/trigger library). The actual decision ("is this job a go, and which template matches it") stays a manual call the Producer makes when they click Start from Template — same category of judgment call no automation could make reliably anyway.

**Correction from earlier planning:** the original plan described a separate ungrouped "Kickoff call" task carrying this automation. That task doesn't exist as a standalone ungrouped item — what's actually in each template is the **first task of the Onboarding & Kickoff phase**, titled "Welcome email sent + client portal link shared (auto via Automation #1)" (Commercial, Brand Story, Conference), confirmed live under its normal phase, not ungrouped. **Podcast has no equivalent "Welcome email" task** (its Show Setup phase doesn't include one per docs/05), so its automation is attached instead to the first Show Setup task, "Confirm show format (interview, solo, panel) and typical episode length." Practical effect: the Folder Generator fires as soon as that first kickoff/setup task is marked complete — not literally the instant the Project is created, but close enough in practice that it still lands before any real file work starts.
